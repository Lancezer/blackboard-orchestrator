# 交给 DSH

按用户的目标决定交给 DSH 的内容、工作区，以及新建还是复用会话。首次交接直接调用 `delegate_to_dsh`，不需要先读取黑板或查询会话。继续已有任务并需要精确返回时，用 `blackboard_sessions` 获取参与会话 ID；在交接要求中保留用户指定的完整后续协作目标。不要假定对方会自动交回。

代码修改前先向用户展示计划并取得明确批准；只读规划可以先进行。涉及的新项目需先获得用户批准。调用 `delegate_to_dsh` 前，通过 shell 读取 `CODEX_THREAD_ID`，提供当前工作区、任务要求和适用的批准状态。工作区不干净时，先按用户意图处理；不要代替用户提交无关改动。

模型、推理强度及原生权限可用 `blackboard_options` 查询；仅在用户要求时调整。成功交接后结束当前回合，等待对方按任务要求决定下一步。
